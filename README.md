# Forklift Simulator Demo

This repository includes a sample Unity script `DriveSimulatorScreen.cs` that outlines a basic
UI setup for a forklift driving simulator targeting Android.

The UI layout includes:

- **Drive controls** (forward, reverse, brake) in the bottom left.
- **Fork controls** (fork up, down, tilt) in the bottom right.
- **Camera switch** button at the top center.
- A placeholder reference for the forklift model and cameras.

The script can be attached to a Unity scene to wire up the buttons and cameras.
